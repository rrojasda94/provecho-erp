## Plantilla para crear un perfil nuevo

```markdown
# Perfil de puesto — <Nombre del puesto>

**Área:** <Operaciones/...> · **Reporta a:** <rol> · **Marcas:** <todas / cuáles>

## Misión del puesto
<1-2 líneas: qué logra el puesto para el negocio.>

## Funciones principales
<5-8 viñetas, empezando por verbo. Lo que hace un día normal.>

## Requisitos
- <Solo lo que el puesto exige de verdad. Nada discriminatorio (Ley 26772):
  no pedir edad, sexo, "buena presencia", estado civil ni foto.>
- Mayor de 18 años (política del grupo) · Carné de sanidad vigente (si toca alimentos)

## Competencias
<3-5: conductas observables, no adjetivos vacíos.>

## Condiciones
- Modalidad de contrato típica: <ver marco-legal-laboral.md §2>
- Jornada: <completa / reducida / parcial> · Horario: <turnos>
- Rango salarial: [[ COMPLETAR: definir con administración ]]
- Uniforme: <qué entrega la empresa>
```
