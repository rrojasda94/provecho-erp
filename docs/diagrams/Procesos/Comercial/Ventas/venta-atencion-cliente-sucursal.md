# SOP — Venta por Atención al Cliente en sucursal

**Área:** Comercial · **Grupo:** Ventas
**Basado en:** PROC-COM-001 (canal Atención al Cliente)

## Objetivo
Tomar el pedido del cliente presencial (mesa, takeout o delivery en sucursal)
sin errores de producto, pago o comprobante.

## Frecuencia
Cada cliente que llega a la sucursal.

## Responsable
Personal de atención al cliente.

## Materiales y equipo
- Terminal POS / ERP con módulo de punto de venta
- Carta física o pantalla digital
- Datáfono / POS de pago con tarjeta

## Pasos
1. Saludo de bienvenida al recibir al cliente.
2. Preguntar el tipo de pedido: mesa, takeout o delivery.
3. Verificar si el cliente está registrado; si no, pedir DNI/teléfono y
   registrar datos.
4. Presentar la carta física o la pantalla digital.
5. Tomar los productos elegidos y armar el carrito en el ERP.
6. Ofrecer un producto adicional (upsell) antes de cerrar el pedido.
7. Repetir el pedido completo al cliente para confirmar.
8. Presentar el total.
9. Si el pedido es para mesa: preguntar si paga ahora o al finalizar
   (RN-POS-005).
10. Presentar el medio de pago disponible, recibir el pago y preguntar el tipo
    de comprobante (boleta o factura) — ver SOP
    [Cobro y emisión de comprobante](../Cobros/cobro-emision-comprobante.md)
    para el detalle de cómo cobrar correctamente.
11. Enviar la orden a cocina.
12. Indicar el tiempo de espera al cliente.

## Excepciones
- Producto sin stock disponible y el cliente no acepta alternativa → retirar
  el producto del carrito antes de continuar.
- Pedido para mesa → el cliente puede elegir pagar de inmediato o al finalizar
  el consumo (RN-POS-005); no asumir uno u otro sin preguntar.
- Cliente se niega a dar DNI para la boleta → emitir boleta simple, sin DNI.

## Problemas frecuentes
Sin incidentes reportados aún — completar esta tabla cuando el equipo
identifique errores recurrentes en la toma de pedido.

## Checklist de verificación
- [ ] Tipo de pedido confirmado (mesa / takeout / delivery)
- [ ] Cliente identificado o registrado
- [ ] Pedido repetido y confirmado antes de cerrar
- [ ] Medio y momento de pago acordado con el cliente
- [ ] Orden enviada a cocina
- [ ] Comprobante emitido

## Evidencia y supervisión
Encargado de turno revisa una muestra de comandas del día contra lo registrado
en el ERP.
