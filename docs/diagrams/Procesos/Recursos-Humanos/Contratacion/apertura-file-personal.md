# SOP — Apertura de file personal

**Área:** Recursos Humanos · **Grupo:** Contratación

## Objetivo
Un expediente único por trabajador con todo su historial documental — ante una
inspección de SUNAFIL o un reclamo, lo que no está en el file no existe.

## Frecuencia
Al firmar el contrato de cada ingreso; se alimenta durante toda la relación
laboral.

## Responsable
Administrador/gerente.

## Materiales y equipo
- Fólder físico por trabajador + carpeta digital (escaneos) — digital en el
  ERP cuando el módulo RRHH esté implementado
- Documentos generados en el proceso de ingreso

## Pasos
1. Abrir el file con carátula: nombres, DNI, puesto, sucursal, fecha de
   ingreso.
2. Archivar en este orden los documentos de ingreso:
   - Ficha de datos del trabajador
   - Copia de DNI / carné de extranjería
   - CV y ficha de entrevista con puntajes
   - Notas de verificación de referencias
   - Oferta escrita y aceptación
   - Contrato firmado + cargo de entrega de copia
   - Copia de carné de sanidad (con fecha de vencimiento visible)
   - Acta de entrega de uniforme
   - Constancias de inducción firmadas
3. Anotar en la carátula las fechas que vencen: contrato modal, periodo de
   prueba, carné de sanidad. Replicar como alertas en el ERP.
4. Durante la relación laboral, todo documento nuevo entra al file el día que
   se genera: memorándums, amonestaciones, solicitudes de vacaciones/permiso,
   actas, constancias de capacitación, renovaciones de contrato.
5. Al cese: agregar carta de renuncia o documentos de término, certificado de
   trabajo (RN-RRHH-002), liquidación (RN-RRHH-003) y constancia de
   devolución de uniforme. El file cerrado se conserva mínimo 5 años.

## Excepciones
- Si un documento se generó y no aparece → reponer con copia o dejar
  constancia escrita del faltante; no dejar el hueco en silencio.
- Si el trabajador rota de sucursal o marca → el file lo sigue (es único por
  trabajador en el grupo), solo se actualiza la carátula.

## Problemas frecuentes
| Síntoma | Causa | Corrección |
|---|---|---|
| En un reclamo no aparece la amonestación firmada | Documento quedó suelto en un cajón | Paso 4: al file el mismo día que se genera |
| Carné de sanidad vencido sin que nadie avise | Vencimientos solo en la memoria de alguien | Paso 3: vencimientos en carátula + alerta en ERP |
| Files mezclados entre sucursales | Se abre un file por local | File único por trabajador, centralizado con el administrador |

## Checklist de verificación
- [ ] File abierto el día de la firma con carátula completa
- [ ] Los 9 documentos de ingreso archivados
- [ ] Vencimientos anotados y con alerta en ERP
- [ ] Documentos posteriores entran el día que se generan
- [ ] Al cese: certificado, liquidación y devoluciones archivados

## Evidencia y supervisión
El file mismo es la evidencia. El administrador audita 2-3 files al azar por
trimestre contra este checklist.
